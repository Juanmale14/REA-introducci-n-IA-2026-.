# 🤖 REA: Introducción a la Inteligencia Artificial (2026)

¡Bienvenido/a al repositorio de este Recurso Educativo Abierto (REA)! Este material ha sido diseñado pedagógicamente para introducir a los estudiantes en las bases, el funcionamiento y el impacto de la Inteligencia Artificial en el año 2026.

El recurso ha sido desarrollado íntegramente con la herramienta de autor **eXeLearning (versión 4.0)** y está optimizado para su visualización web y su libre reutilización.

## 🛠️ ¿Cómo reutilizar o modificar este recurso?
Si eres docente y deseas adaptar este REA a las necesidades de tus alumnos, sigue estos pasos:

1.  **Descarga el archivo fuente:** Descarga el archivo con extensión `.elpx` de este repositorio.
2.  **Instala eXeLearning:** Asegúrate de tener instalado [eXeLearning](https://exelearning.net/) (versión 4.0 o superior).
3.  **Edita el contenido:** Abre el archivo descargado desde la aplicación, realiza las modificaciones oportunas (textos, ejercicios, vídeos) y guarda los cambios.
4.  **Exporta y publica:** Puedes volver a exportarlo como Sitio Web para subirlo a tu propio servidor, plataforma educativa (Moodle) o repositorio personal.
